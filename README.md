# Codyx-Orchestrator

A multi-agent assistant by M. Farid (Mufasa).

This public repository contains user documentation, compiled downloads and update manifests. Development source and its history are maintained separately. You do not need a GitHub account or token to install or update a public release.

## Download

- [Download page](https://install.kingkung.men/downloads)
- [Windows launcher, newest available release](https://install.kingkung.men/downloads/windows)
- [Windows Stable](https://install.kingkung.men/downloads/windows?channel=stable)
- [Windows Beta](https://install.kingkung.men/downloads/windows?channel=beta)
- [All release assets](https://github.com/mufasa1611/codyx-orchestrator/releases)

Choose Stable for the stable release, or Beta to test prerelease improvements. The download page can offer a newer Beta launcher than the Stable channel.

## Windows Installation

1. Download and open `codyx-installer-launcher-windows-x64.exe`.
2. Select Stable or Beta, review the license, and start installation.
3. Enter your name and email when asked, then enter the emailed verification code. Never share that code or an API key in an issue.
4. When installation completes, open the Terminal or Web workspace.

Existing installations retain their configuration. Close active agent jobs before updating. Use the launcher's update or repair action when available; an older launcher can be upgraded by running the latest installer. An uninstall is not required.

## Models and Accounts

Local models depend on your computer's memory and processing capacity. Select an appropriate model during setup. Online providers may require their own API key; availability, prices and quotas are controlled by the provider. No unlimited free service is promised.

The local terminal and authenticated Web UI have different session scopes. Use your own Web UI account to access its history. Keep the launcher open when using its local Web server in an external browser.

## Other Platforms

Linux and macOS CLI archives are listed in Releases. Match the operating system, architecture and libc variant to your machine. A Windows EXE is not a Linux or Android installer. Android availability is shown on the download page; use only a published APK or a supported browser connection, not an unlisted build.

## Updates and Older Installations

Compiled releases continue to use this repository address for public update manifests. [Migration guidance](MIGRATION.md) explains the source-repository separation and older Git-based installations.

GitHub's automatic "Source code" archives contain these public documentation files, not the application development source. Download the explicitly named installer or CLI asset instead.
