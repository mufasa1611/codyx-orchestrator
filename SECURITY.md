# Security

Do not post passwords, API keys, verification codes, email receipts, private logs or personal system information in public issues.

Report security or privacy concerns through the contact information on the [privacy page](https://install.kingkung.men/privacy). Include affected versions and file or commit identifiers, not usable secret values.

If a credential was exposed, revoke or rotate it at its provider. Making a repository private does not invalidate a previously copied credential.
