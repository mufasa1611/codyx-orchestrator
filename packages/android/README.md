# codyx Android

Android packaging for codyx uses a Trusted Web Activity generated by Bubblewrap.
The app opens the hosted codyx web experience, so web updates are fetched when
the app starts. Native APK/AAB updates are distributed through GitHub Releases or
the Play Store.

## Build Locally

The build needs JDK 17 and the Android SDK. Configure Bubblewrap once:

```bash
mkdir -p ~/.bubblewrap
cat > ~/.bubblewrap/config.json <<EOF
{"jdkPath":"$JAVA_HOME","androidSdkPath":"$ANDROID_HOME"}
EOF
```

Then build from this package:

```bash
bun run build:unsigned
```

For signed release artifacts, provide `android.keystore` plus:

```bash
export BUBBLEWRAP_KEYSTORE_PASSWORD=...
export BUBBLEWRAP_KEY_PASSWORD=...
bun run build
```

## Digital Asset Links

Trusted Web Activity verification requires serving an asset links file from:

```text
https://app.codyx.ai/.well-known/assetlinks.json
```

Generate the fingerprint for the signing key and update `twa-manifest.json`.
Without a valid asset links file, Android falls back to Custom Tabs.
